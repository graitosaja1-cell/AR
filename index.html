☁️ Sync Antar-Device (Cloud)

Sinkron otomatis (langsung aktif di semua device, tanpa PIN / kode): perubahan di device ini dikirim ke cloud ±20 detik setelah selesai, dan saat aplikasi dibuka data terbaru dari cloud diambil otomatis bila device ini tidak punya perubahan yang belum terkirim. Jika cloud dan device sama-sama berubah, Anda akan ditanya data mana yang dipakai. Tombol Upload/Ambil manual tetap bisa dipakai (data terbaru MENIMPA data di device tujuan).
